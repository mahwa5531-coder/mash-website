# 3D Spreadsheet Engine

Mash integrates an enterprise spreadsheet canvas designed to handle multi-tab workbooks, complex formula evaluation, and 3D vector data projections.

## Supported Formats

- `.xlsx` (Microsoft Excel OpenXML)
- `.csv` (Comma-Separated Values)
- `.tsv` (Tab-Separated Values)

## Multi-Sheet Navigation

Workbooks open with full sheet tab support. For example, statutory audit workbooks automatically split across:
1. **Executive Dashboard:** Summary metrics, KPIs, and 3D spatial bar charts.
2. **Monthly Trend Analytics:** Time-series variations, volatility curves, and 3D pie discs.
3. **General Ledger Audit:** Line-by-line voucher listings with automated variance flagging.

## 3D Vector Visualizations

Unlike flat bitmap charts, Mash renders charts in a 3D vector space:
- **Interactive Orbit:** Click and drag to inspect chart depth and column relationships.
- **Dynamic Extrusion:** Height correlates with financial magnitude; depth represents quarterly periods.
- **Formula Sync:** Modifying a cell in the table immediately triggers re-projection of the 3D bars.
