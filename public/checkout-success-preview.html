Data Audit: What Is Shown vs. What Is Kept Hidden (Security Best Practices)

✓ Shown on Screen & Receipt:
  • • Razorpay Payment ID (pay_...) — Needed for bank reconciliation.
  • • Order Reference (order_...) — Matches merchant records.
  • • Billed Email (from Google OAuth session) — Confirms account ownership.
  • • Amount in INR (amount_paise / 100) — Exact paise math (₹1,999.00).
  • • SAC / Tax Classification — Essential for CA firm expense filing.
  • • Active Duration (30 days / 365 days) — Clear validity.
✗ Kept Hidden (Security & Cleanliness):
  • • Razorpay Signature (64-hex HMAC) — Server-side only; zero client value.
  • • API Secret Keys / Webhook Secrets — Never sent to browser.
  • • Internal Tenant ID (ten_...) / User ULID — Confusing to humans.
  • • OpenRouter API Keys — Cloud-held only (desktop never sees it).
  • • Raw JSON error dumps — Clean user messages instead of tracebacks.
